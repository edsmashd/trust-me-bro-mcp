# Trust Me Bro MCP

Remote MCP server for [Trust Me Bro](https://trustmebro.to) — fact-check receipts: search published claim verdicts with cited evidence, or verify a new claim.

## Connect

Point any MCP client at:

`https://trustmebro.to/mcp`

(Streamable HTTP.)

## Registry

- Official MCP Registry: `to.trustmebro/trust-me-bro`
- [Glama listing](https://glama.ai/mcp/connectors/to.trustmebro/trust-me-bro)
